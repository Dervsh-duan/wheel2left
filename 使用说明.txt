Wheel2Left · 滚轮变左键
========================

把鼠标滚轮变成左键点击，作用在驱动层，全屏游戏里也有效。


【第一次使用】
------------

1. 右键 install_driver.bat，选择「以管理员身份运行」
2. 重启电脑（必须，否则驱动挂不到鼠标上）
3. 双击 Wheel2Left.exe，UAC 弹窗点「是」
4. 切到游戏窗口，滚一下滚轮 —— 程序会自动锁定它
5. 之后滚轮就等于左键了


【没反应怎么办】
--------------

先看界面上的「已触发 N 次」有没有变化：

  涨了    → 驱动拦到了，只是前台窗口不对。
            点「锁定前台程序」重新锁定一次。

  不涨    → 驱动没挂上。依次检查：
            1. 装完驱动后重启过没有
            2. Windows 设置 → 隐私和安全性 → 设备安全性
               → 内核隔离 → 内存完整性 是否开着
               （开着会拒绝加载这类驱动，需要关掉再重启）
            3. 确认 Wheel2Left.exe 和 interception.dll 在同一目录
            4. 日志：%TEMP%\Wheel2LeftDriver.log


【三种生效范围】
--------------

指定程序（默认）
    只有锁定的游戏里滚轮才是左键，桌面、浏览器完全不受影响。

仅全屏
    前台窗口铺满屏幕时才转换。懒得配置又怕误点桌面时用。

全部窗口
    任何地方滚轮都是左键。临时用，桌面上会误点图标。


【热键】
------

Ctrl + Alt + Shift + R    随时开关


【注意】
------

* 不要用在带反作弊的在线游戏里（EAC / BattlEye / Vanguard 等），
  可能拒绝启动甚至封号。
* 很多 galgame 用滚轮回看历史对话（backlog）。开启后这个功能就没了，
  需要回看时按热键临时关掉。
* 关闭程序 → 滚轮立刻恢复正常，不用卸载驱动。
* 每次启动都会弹 UAC，因为打开驱动设备需要管理员权限。


【卸载驱动】
----------

右键 uninstall_driver.bat → 以管理员身份运行，然后重启。
如果你装过罗技/雷蛇等厂商的驱动，卸载脚本会把过滤注册恢复成系统默认值，
请按提示用备份的 backup_*.reg 还原，或重装厂商驱动。
